# 📱 App ListView

Aplicativo mobile desenvolvido em **React Native** utilizando **listas para exibição de dados**.
O projeto demonstra como criar interfaces que exibem informações em formato de lista, permitindo organizar e visualizar múltiplos itens dentro de um aplicativo mobile.

Componentes de lista são muito utilizados em aplicações modernas para mostrar **dados, cadastros, produtos ou registros**, tornando a navegação mais organizada e intuitiva. ([Gist][1])

---

# 🚀 Funcionalidades

* 📋 Exibição de dados em formato de lista
* 🔄 Atualização dinâmica de itens
* 📱 Interface mobile simples
* ⚡ Estrutura básica de listas em **React Native**
* 🎨 Layout organizado para melhor visualização dos dados

---

# 🛠️ Tecnologias utilizadas

* **React Native**
* **JavaScript**
* **Expo**
* **Componentes de lista do React Native**

# ▶️ Como executar o projeto

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/JoaoRamponi/appListView.git
```

### 2️⃣ Entrar na pasta do projeto

```bash
cd appListView
```

### 3️⃣ Instalar as dependências

```bash
npm install
```

### 4️⃣ Executar o projeto

```bash
npx expo start
```
